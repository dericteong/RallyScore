# User Stories

## Setup

- As a scorekeeper, I want to enter both teams' player names before a game so the scoreboard is easy for players to identify.
- As a scorekeeper, I want to select which team serves first so the game starts with the correct `0 - 0 - 2` call.
- As a scorekeeper, I want the setup screen to stay usable when the keyboard is open so I can enter names on a real phone.

## Live Scoring

- As a scorekeeper, I want to tap the team that won the rally so I do not need to think about side outs or server number.
- As a first-time user, I want the screen to make the current score obvious without reading instructions.
- As a player on court, I want the score to be readable from a distance.
- As a player, I want the score called out after a rally so everyone knows the current call.

## Corrections

- As a scorekeeper, I want to undo the last rally so I can quickly fix a wrong tap.
- As a scorekeeper, I want undo to restore scores, serving team, server number, and side outs together.

## Timed Play

- As a club player, I want scores to continue beyond 11 because some games are run by a timer rather than a target score.

## Game End

- As a scorekeeper, I want an End control with confirmation so I do not accidentally clear a game.

## Wear OS

- As a watch user, I want a compact scoreboard on my wrist so I can score without holding the phone.
- As a future watch user, I want the watch to control the phone scoreboard so the phone can remain connected to a display.

## External Display

- As an organizer, I want to show the scoreboard on a portable monitor so players and spectators can see the score clearly.
